# Base Calculator

A simple C++ program that converts a decimal number into different number systems:

* Binary (Base 2)
* Octal (Base 8)
* Hexadecimal (Base 16)

## Features

* Convert decimal numbers to binary.
* Convert decimal numbers to octal.
* Convert decimal numbers to hexadecimal.
* Easy-to-use console interface.
* Fast and lightweight implementation.

## How It Works

1. Enter a decimal number.
2. Select the conversion type:

   * `1` for Binary
   * `2` for Octal
   * `3` for Hexadecimal
3. The program displays the converted result.
