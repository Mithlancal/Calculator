# Conversion Cal

A simple **menu-driven C++ program** that performs multiple unit conversions including:

- Length
- Height
- Weight
- Volume
- Speed
- Time

The program allows repeated conversions in a single run using a loop-based menu system.

---

# 🚀 Features

- Multi-category unit conversion system
- Easy interactive menu interface
- Continuous usage without restarting program
- Covers common real-world unit conversions
- Simple and beginner-friendly C++ structure

---

# 📊 Conversion Categories

## 📏 1. Length Conversion
- Meters → Centimeters
- Meters → Kilometers

---

## 📐 2. Height Conversion
- Centimeters → Meters
- Centimeters → Feet

---

## ⚖️ 3. Weight Conversion
- Kilograms → Grams
- Kilograms → Pounds

---

## 🧪 4. Volume Conversion
- Liters → Milliliters

---

## 🚗 5. Speed Conversion
- km/h → m/s

---

## ⏱️ 6. Time Conversion
- Hours → Minutes
- Hours → Seconds
