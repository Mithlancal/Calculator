\# 🌡️ Temperature Converter in C++



A simple C++ console program to convert temperatures between \*\*Celsius, Fahrenheit, and Kelvin\*\*.



\---



\## 🚀 Features



\- Celsius → Fahrenheit  

\- Fahrenheit → Celsius  

\- Celsius → Kelvin  

\- Kelvin → Celsius  

\- Menu-driven interface  

\- Runs in loop until user exits  



\---



\## 🧠 Formulas Used



\- Fahrenheit = (Celsius × 9/5) + 32  

\- Celsius = (Fahrenheit − 32) × 5/9  

\- Kelvin = Celsius + 273.15  

\- Celsius = Kelvin − 273.15
