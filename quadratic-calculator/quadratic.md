# Quadratic Cal

A simple C++ program to find the roots of a quadratic equation of the form:
Shridharacharya Method:
\[
ax^2 + bx + c = 0
\]

It handles:
- Real and distinct roots
- Real and equal roots
- Complex roots (optional user confirmation)

It also uses the **Newton-Raphson method** to compute square roots instead of built-in functions.

---

# 🚀 Features

- Takes coefficients `a`, `b`, and `c` as input
- Computes discriminant
- Determines root type automatically
- Calculates:
  - Real roots
  - Equal roots
  - Complex roots (optional mode)
