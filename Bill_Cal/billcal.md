# 🧾 Multi-Person Billing System (C++)

## 📌 Overview
This is a simple C++ console application that calculates the total bill for multiple people, including country-based tax rates. Each person can order multiple items, and the program computes their final payable amount.

---

## ⚙️ Features
- Supports multiple people
- Each person can order multiple items
- Country-based tax calculation
- Clean bill summary output
- Uses structured data (`struct`) for clarity

---
