# Interest Cal

A simple **menu-driven C++ program** that calculates:

- Simple Interest (SI)
- Compound Interest (CI)

It helps users quickly compute total amount and interest earned based on input values.

---

# 🚀 Features

- Simple Interest calculation
- Compound Interest calculation
- User-friendly menu system
- Repeated calculations without restarting program
- Formatted output using `iomanip`
