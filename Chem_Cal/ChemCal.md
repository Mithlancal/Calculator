# 🧪 ChemCal - Chemistry Concentration Calculator

A simple C++ console application to calculate common chemical solution concentrations:
- Molarity
- Molality
- Normality

---

## 📌 Features

- Calculates **Molarity (M)** = moles / liters of solution
- Calculates **Molality (m)** = moles / kilograms of solvent
- Calculates **Normality (N)** = gram equivalents / liters of solution
- Input validation for division by zero
- Interactive menu-driven interface
- Clean console output with formatted precision
